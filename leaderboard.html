How to read it

Full trust — the ranking metric
FL ∧ APR ∧ Reasoning on the same instance, with a Wilson 95% interval. The bar shows the interval; the tick is the point estimate.
Fix without localizing
Of instances the model resolved, the share where it pointed at the wrong fault line — a passing patch built on a wrong diagnosis. Lower is better.
Attempted
Instances the model produced a localization or patch for in ≥2 runs. Engagement, not correctness — context for a low score.
Robustness
Retention under semantics-preserving code transforms. Pending until the transformed runs complete.

Why joint trust

Single-axis competence overstates trustworthiness. A model can pass tests while misreading the bug: across this set, ~31% of resolved patches localized the wrong line. The leaderboard therefore leads with the one number that requires every axis at once — the metric no single-axis score can stand in for.

Verdicts collapse each model's three runs by majority vote, so a single lucky run can't carry a rank; run-to-run instability shows up as a lower joint score.
